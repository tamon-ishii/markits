# Markits Windows v0.8.2

- Unified badges and step arrows into Number Badge, with independent arrow and target-box visibility settings.
- Unified rectangles and rounded rectangles, with a live corner-roundness slider from square corners to maximum rounding.
- Added solid, dashed, and dotted shape outlines and no-fill, light-fill, and solid-fill options for rectangles and circles.
- Added mark copy/paste with Ctrl+C / Ctrl+V, toolbar buttons, multiple selection, and undo support.
- Made drag handles follow all marks during movement and resizing, including curved-arrow endpoints, control points, and guide lines.
- Made callout target rectangles visible in previews and exports, with a visibility toggle, and simplified the move icon.
- Made labels move and hit-test by their visible bodies, without snapping to an invisible target rectangle.
- Matched tapered-arrow thickness to the selected stroke width instead of the arrow length.
- Removed redundant mark-style preset buttons, pin tags, bullseyes, and dividers from the editor tools.
- Silently skip removed or unsupported marks when reopening old images or pasting, while preserving the hidden state of supported marks.
